# 管理端数据驱动的监管大屏

## 已批准设计
保留中央真实地图边界、机构坐标、标签引线和地图联动。外围采用深蓝青色三列布局（23/54/23），支持1920×1080及普通桌面。
左：确诊在管人群性别/年龄、可切换机构排行（问卷/肺功能/高危）及完整表、穿戴摘要和脱敏动态。
中：六张指标卡、机构地图、合并症双列前十排行（统一尺度，一人可有多种），通过页签保留月趋势及管理分级。
右：筛查概况、GOLD、风险和综合评估、档案质控。
顶部：年度、权限内机构范围、时钟、全屏和返回。

## 数据与架构
原生ES模块组件独立可维护，旧发布资源保留为legacy入口。Manager新增薄聚合接口复用ReportStatsService；现有人群统计扩展性别/年龄未知/风险/综合评估/管理分级。业务权限和OrgRule范围原样复用，无新数据库。
年度事件（问卷人次、≥16分问卷人次、肺功能检查人次、随访人次）与当前在管/监测状态分组标示。GOLD已分级为分母，未分级另列；质控为档案质控。
Node只代理允许的只读Manager接口并转发用户Authorization；无服务账号、无旧SQL回退。普通统计60秒、监测20秒，筛选变更取消旧请求且清空旧范围。失败明确提示并展示该范围上次成功时间。
地图元数据仅为几何/坐标，按字符串机构ID匹配。离线预览不显示虚构业务数字。
